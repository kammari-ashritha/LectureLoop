
# 📚 LectureLoop AI

**LectureLoop AI** is an intelligent educational platform designed to streamline the learning process for students. Built using Python and Streamlit, this application leverages Artificial Intelligence to transform how students interact with lecture materials.

🚀 **Developed for the TechSprint AI – Open Innovation Challenge (GDG On Campus).**

## 🌟 Overview

LectureLoop AI aims to bridge the gap between passive listening and active learning. By utilizing generative AI, the platform helps users digest complex lecture content efficiently.

## 🛠️ Tech Stack

* **Frontend & UI:** [Streamlit](https://streamlit.io/)
* **Language:** Python
* **AI/LLM:** Google Gemini
* **Database:** Firebase
* **Authentication:** Custom Streamlit Auth

## ⚙️ Installation & Setup

Follow these steps to set up the project locally:

1.  **Clone the repository:**
    ```bash
    git clone (https://github.com/kammari-ashritha/LectureLoop.git)
    cd LectureLoop-AI
    ```

2.  **Create a virtual environment (Optional but recommended):**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # Mac/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the application:**
    ```bash
    streamlit run app.py
    ``
